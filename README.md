## 🚀 Featured Projects

### 🧩 WhyUI — Browser UI Interaction Debugger
[SkyDevLab/WhyUI](https://github.com/SkyDevLab/WhyUI)

A Microsoft Edge Manifest V3 extension that explains why a web UI element is disabled, hidden, covered, read-only, off-screen, or otherwise not interactive. It uses deterministic browser-level analysis rather than external AI APIs.

**Keywords:** browser extension · Microsoft Edge · Manifest V3 · TypeScript · React · frontend debugging · UI debugging · DOM · CSS

### 🌐 Website Upgrade Detector
[SkyDevLab/website-upgrade-detector](https://github.com/SkyDevLab/website-upgrade-detector)

A browser extension for detecting website technologies and identifying opportunities to understand or upgrade a site's web stack.

**Keywords:** web technology detection · browser extension · Microsoft Edge · JavaScript · TypeScript · web stack · developer tools

### 📦 SkyWebFramework
[SkyDevLab/SkyWebFramework.Middleware](https://github.com/SkyDevLab/SkyWebFramework.Middleware) · [Dependency Injection](https://github.com/SkyDevLab/SkyWebFramework.DependencyInjection)

A collection of reusable **ASP.NET Core / .NET developer libraries** for middleware, dependency injection and application infrastructure.

**Keywords:** .NET · ASP.NET Core · C# · middleware · dependency injection · NuGet · developer library · web framework

### 🩺 PR Doctor
[SkyDevLab/pr-doctor](https://github.com/SkyDevLab/pr-doctor)

A client-side GitHub pull-request diagnostic tool that analyzes CI checks, reviews, merge conflicts, draft state and other signals to produce an actionable PR diagnosis.

**Keywords:** GitHub · pull request · CI/CD · GitHub Actions · developer tools · code review · TypeScript

### 🤖 Website AIEO Checker
[SkyDevLab/Aieo](https://github.com/SkyDevLab/Aieo)

An open-source website audit tool focused on **AI search readiness, AEO/AIEO, crawlability, structured data, entity clarity, content structure and answer readiness**.

**Keywords:** AIEO · AEO · AI search · AI Overviews · structured data · Schema.org · SEO · entity clarity · website audit
